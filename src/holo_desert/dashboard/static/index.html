    Your first experiment
    1. Choose what to observe
      Start from one of the examples or create a custom scenario. Read “What to observe”.
    2. Start the simulation
      The Start button initialises HoloOcean and DESERT. The first Docker start-up may take a few minutes.
    3. Explore the map
      Select a drone or a message. Positions are measured; arrows follow the actual network events.
    4. Follow the communications
      Blue: observed transmission. Green: delivery. Orange: TTL expired, cause unknown. An acoustic error alone does not prove a final loss.
    5. Read the results
      Generated does not mean transmitted. The delivery ratio excludes messages still pending. Analysis provides complete metrics and statistics.
    6. Customise the experiment
      Settings adjusts the network for the next run. My scenarios lets you define drones, motion, flows and relays without writing YAML.
    7. Keep what you need
      Export results downloads the ZIP. Custom scenarios are saved; ordinary results are temporary, so export them before resetting.
    

    About the laboratory
    HoloOcean 2.3 handles physics and motion. DESERT 4.0 handles the acoustic network, propagation and interference.
    The web map shows a 2D view of the observations; the 3D world remains in the HoloOcean window. Engines, formulas and the example configurations are unchanged.
